# Hooked (Post-LD) 简体中文汉化补丁

非官方社区汉化补丁。把游戏界面文本整体换成简体中文，并把**画在贴图上的标题字**
（`inventory` / `extract` / `fishing` / `Shop` 等）按原像素风格重绘成中文。

> 补丁**不含游戏本体**，只包含被修改的游戏资源文件；请先购买/拥有正版游戏。

## 安装 / 卸载

1. 解压，把 `Hooked_汉化补丁` 整个文件夹放进**游戏根目录**（和 `Hooked.exe` 同一层）；
2. 双击 `安装汉化.bat`；
3. 想还原就双击 `卸载汉化.bat`。

安装器会：校验原版文件哈希（版本不符会提示并询问）→ 把原文件备份到「备份原文件」→
覆盖 → 再复核一遍结果哈希。卸载后与原版逐字节一致（有 sha256 复核）。

## 补丁做了什么

* **文本**：TextMeshPro 组件 48 个字段（道具 / 鱼 / 升级的提示框标题与说明、操作提示、失败画面），
  原文是俄语与英语混排，均已翻译；
* **代码内文本**：漂浮提示 `Not enough money!` → `钱不够！`（等长原地替换，不移动元数据堆）；
* **中文字体**：把随包的动态字体 `LiberationSans SDF - Fallback` 的源字体换成
  **缝合像素字体 12px 简体**（SIL OFL），并登记为界面字体的回退字体；
  拉丁字母 / 数字仍用游戏原字体；
* **图片里的字**（重绘，含禁用 / 高亮变体，保持原像素字体风格与配色）：

  | 位置 | 原文 | 中文 |
  |---|---|---|
  | 物品栏标题 | inventory | 背包 |
  | 右侧面板 | items / upgrades | 物品 / 升级 |
  | 生命徽章 | HP | 生命 |
  | 仓库按钮（3 个变体） | storage | 仓库 |
  | 钓鱼按钮（3 个变体） | fishing | 钓鱼 |
  | 撤离按钮（3 个变体） | extract | 撤离 |
  | 码头霓虹招牌（11 帧） | Shop | 商店 |

  这两张贴图的数据在 1 GB 的 `sharedassets0.assets.resS` 里，补丁**不整份替换大文件**：
  安装器只把 **392 段、共 44 KB** 的改动字节原位写回（文件长度不变），
  卸载时按同一张段表写回原始字节，前后均有 sha256 校验。

## 版本记录

* **v1.0**：首版（文本 + 字体 + 贴图内文字）。
* **v1.0.1**：修掉「鱼/道具的效果说明仍是英文」（同一物体多字段被互相覆盖的构建缺陷）；
  补齐全部贴图内文字。
* **v1.0.2**：修掉图集写回时的上下翻转方向错误 —— 表现为物品栏展开后出现一块
  **镜像的英文 `inventory` 面板**，且卸载时图集还原校验失败（段表记录的原始字节与
  文件真字节不符）。现在安装 / 卸载全程按文件字节序计算，整文件 sha256 可复核。
